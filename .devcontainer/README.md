# Nursery Command Center: online demo

This window is GitHub Codespaces. You do not need to type anything here.

- **First time:** setting up takes about 5 to 8 minutes. When the app is ready, it opens in a new browser tab by itself.
- **If no tab opens:** click **Ports** at the bottom of this window, then the globe icon next to **Nursery app (3000)**.
- **On your phone:** copy the address of the app tab (it ends in `-3000.app.github.dev`) and open it on the phone. If the phone asks you to sign in to GitHub, sign in with the same account.
- **Signing in to the app:** the sign-in screen lists one demo account per role. Tap one. The password for all of them is shown there too.
- **Made-up data only.** Never enter real children, families or staff here. This demo is not hosted in Egypt.
- **When you are done:** close the tabs. The codespace stops by itself after 30 minutes without use. Next time, open it again from <https://github.com/codespaces>; it starts in about a minute, with the demo accounts reset and today's attendance filled in.

GitHub gives every account 120 free hours a month (60 hours of this demo). Without a card on file it simply stops when they run out; nothing is ever charged.

If something looks wrong, the app's log is in `/tmp/nursery-demo.log`.
